# Графика, анимация, звук

> Читать перед любой визуальной задачей. Главное правило: **не крутить один способ по кругу.**
> 2 итерации не дали результата, похожего на `refs/`? Переходи на следующую ступень лестницы.

## Лестница инструментов (сверху вниз, от дешёвого к дорогому)

### Ступень 0. Что уже есть
- `assets/` и `assets/README.md`. Если подходящий ассет есть, используй его. Не рисуй заново.

### Ступень 1. Графика кодом (Claude делает это хорошо)
Подходит для: стрелок, сеток, плиток, кнопок, иконок, рамок, частиц, фонов-градиентов, простых персонажей из фигур.
- **SVG** в `assets/svg/`: чистые формы, палитра из `src/config/theme`.
- **Canvas / Graphics API движка**: процедурные фигуры, частицы.
- **Анимация**: твины движка (easing `Back.Out`, `Quad.InOut`), squash & stretch, лёгкий bounce. Тайминги в конфиге: 150–300 мс на отклик тапа.
- **Шейдеры** (glow, blur, wave): только если движок поддерживает и это дешево по fps.

### Ступень 2. Скрипты-конвертеры (автоматизация)
Подходит для: растеризации SVG→PNG, @1x/@2x, спрайт-листов, обрезки, перекраски.
- Node: `sharp` (devDependency) или Python: `Pillow` (`python -I tools/<script>.py`).
- Скрипты лежат в `tools/`, их вывод в `assets/generated/`. Генерируется командой `npm run assets`.
- Размеры и пропорции проверять скриптом, а не открывать картинки «на глаз».

### Ступень 3. Свободные паки (через `researcher`)
- Графика: Kenney.nl (CC0), OpenGameArt.org (смотреть лицензию у каждого), game-icons.net (CC-BY 3.0).
- Шрифты: Google Fonts (OFL).
- Звуки: Kenney (CC0), генерация кодом через jsfxr / Web Audio (лицензия не нужна), freesound.org (только CC0 / CC-BY).
- Каждый чужой файл записывай в `assets/CREDITS.md`: файл, автор, ссылка, лицензия.
- Скачивание файла требует «ок» пользователя (назвать файл, источник, размер).

### Ступень 4. AI-генерация картинок (для иллюстраций, персонажей, фонов)
Claude не рисует растровые картинки сам. Варианты:
- **A (по умолчанию)**: подготовить пользователю готовый промпт в `docs/art-prompts.md`:
  объект, стиль (по `refs/`), палитра (hex), ракурс, **прозрачный фон**, размер в px, количество кадров, «game asset, no text».
  Пользователь генерирует картинку в своём сервисе и кладёт её в `assets/incoming/`. Дальше скрипт со ступени 2 нарезает и подгоняет.
- **B**: MCP-сервер или API генерации изображений. Подключается **только после «ок»**, ключ хранится в `.env`.

### Ступень 5. Человек
Если и это не попадает в нужное ощущение, честно скажи, что именно не получается, и предложи упростить стиль под ступень 1.

## Стиль: держать единым
- Палитра, радиусы скругления, толщины линий и тени хранятся в `src/config/theme.ts`. Новых цветов «на глаз» не вводить.
- Одна визуальная идея на экран. Сравнивай с `refs/` по трём пунктам: цвет, форма, движение.

## Проверка визуала
1. Скриншот 390×844 и 1280×800 (`scale: 0.5`).
2. Сравнить с `refs/`: выписать максимум 3 главных отличия.
3. Исправить самое важное, повторить. **Максимум 2 круга**, потом следующая ступень или вопрос пользователю.
