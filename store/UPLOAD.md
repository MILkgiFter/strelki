# Что куда грузить в Play Console

Все файлы для загрузки лежат в **`C:\гейм\store\play-upload\`**. Тексты на всех языках уже вставлены и сохранены, остались только картинки: перетащить мышкой.

## 1. Страница приложения (значок, баннер, скриншоты)
Ссылка: https://play.google.com/console/u/0/developers/7080248602921152147/app/4975218698006159652/store-listings/default/edit

На странице вверху есть «Выбор языка» с выпадающим списком. Выбираешь язык, прокручиваешь до «Графических ресурсов» и перетаскиваешь файлы. Внизу жмёшь «Сохранить как проект».

**Язык по умолчанию (Русский – ru-RU):**
| Поле | Файл |
|---|---|
| Значок приложения (512×512) | `play-upload\icon-512.png` |
| Картинка для описания (1024×500) | `play-upload\feature-graphic-ru.png` |
| Скриншоты для смартфона | все 7 файлов из `play-upload\ru\` (выделить все и перетащить разом) |

**Остальные языки:** в каждом языке достаточно скриншотов (и баннера, где он есть). Значок общий, его в переводах не трогают.
Если для языка картинки не загрузить, Play покажет русские, поэтому лучше загрузить везде.

## 2. Сборка (AAB) во внутреннее тестирование
Ссылка: https://play.google.com/console/u/0/developers/7080248602921152147/app/4975218698006159652/tracks/internal-testing
«Создать выпуск» → перетащить `C:\гейм\android\app\build\outputs\bundle\release\app-release.aab` → «Далее» → «Сохранить и опубликовать».

## 3. Отправить изменения на проверку
Ссылка: https://play.google.com/console/u/0/developers/7080248602921152147/app/4975218698006159652/publishing
«Обзор публикации» → «Отправить изменения на проверку» (страница, анкеты, переводы уходят вместе).
